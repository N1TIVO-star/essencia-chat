ESSÊNCIA CHAT V6

NOVIDADES
- Clique com o botão direito em uma transmissão para controlar volume.
- Slider do áudio da transmissão funciona em tempo real.
- Slider da voz do participante funciona em tempo real.
- Na transmissão ampliada/tela cheia existe uma barra de volume fixa.
- PostgreSQL Neon configurado via .env.
- O banco remoto é a persistência principal; data/db.json continua como backup local.

BANCO
A V6 já contém um arquivo .env com a DATABASE_URL informada para esta versão.
Quando trocar o banco, edite somente a variável DATABASE_URL.

ATUALIZAÇÃO
1. Faça backup da pasta data/ da versão atual.
2. Extraia a V6.
3. Se quiser importar seus dados atuais para o Neon, copie sua pasta data/ antiga para dentro da V6 ANTES da primeira execução.
4. Rode:
   npm install
   npm start
5. Faça Ctrl+F5 no navegador.

Na primeira inicialização, se a tabela no Neon estiver vazia, a V6 importa automaticamente o db.json local.
