ESSÊNCIA CHAT V10 — MOBILE

FOCO DESTA VERSÃO
Interface de celular refeita.

CORREÇÕES
- Menu servidores/canais responsivo até 320px.
- Scrim para fechar painel tocando fora.
- Botão X no menu lateral.
- Lista de membros móvel com botão X.
- Composer corrigido: botão Enviar visível no celular.
- Ajuste para teclado virtual usando visualViewport.
- Safe area para iPhone/Android.
- Chat e anexos adaptados.
- Voice UI adaptada para toque.
- Transmissão ampliada e volume adaptados.
- Modais em formato bottom-sheet.
- Navegação lateral fecha ao abrir chat/canal/PV.

ATUALIZAÇÃO
1. Preserve seu .env / DATABASE_URL.
2. Extraia a V10.
3. Rode npm install
4. Rode npm start
5. No celular, feche e abra o site novamente ou limpe o cache.
6. No desktop, Ctrl+F5.

O backend/PostgreSQL e as funções da V9 foram mantidos.
